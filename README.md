### 🐉 About Me
Hi there! I'm **CommunistGoku5317**, a developer passionate about retro game reverse engineering, binary file formats, and pushing browser-based tools beyond their limits. 

My main mission right now is making **Dragon Ball Z: Budokai Tenkaichi 3** modding more accessible—no heavy desktop software required, just pure JavaScript running straight in your browser.

---

### 🛠️ Featured Project
* **[PSRET-turbowarp-tenkaichi-3-modding-tool](https://github.com/CommunistGoku5317/PSRET-turbowarp-tenkaichi-3-modding-tool)**  
  A browser-based **AFS/AFL/PAK Explorer, Rebuilder & QRS 4/8-bit Texture Decoder** built as an unsandboxed TurboWarp extension (`BT3_Web_Modder.js`). Designed to inspect and modify PS2/Wii game files with ease.

### 💻 Tech Stack & Interests
* **Languages:** JavaScript (ES6+), Scratch / TurboWarp Extensions
* **Reverse Engineering:** Binary parsing, proprietary archives (`AFS`, `AFL`, `PAK`), indexed color palettes (`QRS` 4-bit / 8-bit textures)
* **Favorite Games:** Dragon Ball Z: Budokai Tenkaichi 3 (PS2/Wii)
