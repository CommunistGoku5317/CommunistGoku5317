### 🛠 Featured Projects

* **[PSRET-turbowarp-tenkaichi-3-modding-tool](https://github.com/CommunistGoku5317/PSRET-turbowarp-tenkaichi-3-modding-tool)** — A complete browser-based and desktop archive explorer, rebuilder, and **QRS texture decoder** (4-bit & 8-bit) for *Dragon Ball Z: Budokai Tenkaichi 3* (PS2/Wii). Available both as an unsandboxed TurboWarp/CodeTorch extension (`BT3_Web_Modder.js`) and a standalone desktop utility with GUI and scriptable CLI (`.PSRTCM`). Supports streaming browsing of nested `.afs`, `.pak`, and `.afl` archives, 2048-byte aligned rebuilding, PS2 GS deswizzling, CT32 CSM1 CLUT unscrambling, live canvas preview, and one-click PNG export.
* **[Hex-Editor-Pro-TurboWarp](https://github.com/CommunistGoku5317/Hex-Editor-Pro-TurboWarp)** — A lightweight, high-performance unsandboxed TurboWarp extension that embeds a full-featured binary and hexadecimal editor directly inside Scratch/TurboWarp projects. Powered by an **HTML5 Virtual Scroller** with DOM pooling and a 64 KB sliding window cache to smoothly handle multi-megabyte files without freezing the browser. Includes a **Magic Bytes format detector** (with native recognition for PS2/BT3 formats like `.afs`, `.afl`, `.tm2`, `.pak`, `.adx`, `.elf`, `.iso`), a live **Data Inspector** (Little/Big Endian), direct Hex/ASCII editing with `Ctrl+Z` undo, and Scratch blocks for programmatic binary patching.
* **[TurboWarp-Chiptune-and-MIDI-Suite](https://github.com/CommunistGoku5317/TurboWarp-Chiptune-and-MIDI-Suite)** — A collection of zero-dependency, unsandboxed TurboWarp extensions for retro game audio and music visualization. Includes `chiptune-poly-midi.js` (a custom SMF Format 0/1 binary MIDI parser paired with a 4-voice Web Audio API polyphonic chiptune synthesizer supporting per-track waveforms, 10 `localStorage` slots, and Base64 embedded songs) and `midi-to-sheet-music.js` (an interactive HTML5 `<canvas>` grand-staff sheet music renderer with synchronized Web Audio playback, Scratch reporter blocks, and one-click PNG export).
